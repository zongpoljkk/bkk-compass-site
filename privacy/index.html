BKK Compass Privacy Policy

Effective October 16, 2026

BKK Compass is a quiz app for learning Bangkok metro stations. This policy describes what the iOS app does with information.

BKK Compass เป็นแอปแบบทดสอบสำหรับจำสถานีรถไฟฟ้ากรุงเทพ นโยบายนี้อธิบายว่าแอปบน iOS จัดการข้อมูลอย่างไร

Information we collect

The app does not require an account. It does not collect, transmit, or sell personal information. Scores and streaks are stored only on your device.

แอปไม่ต้องสมัครบัญชี ไม่ได้เก็บ ส่ง หรือขายข้อมูลส่วนบุคคล คะแนนและสถิติถูกเก็บไว้บนเครื่องของคุณเท่านั้น

Fare updates

When it opens, the app may download the latest public fare table from this website, which is hosted on GitHub Pages. The request contains no personal information. Like any website, GitHub may record your IP address in its server logs; see the GitHub Privacy Statement.

เมื่อเปิดแอป แอปอาจดาวน์โหลดตารางค่าโดยสารล่าสุดจากเว็บไซต์นี้ (โฮสต์บน GitHub Pages) คำขอนี้ไม่มีข้อมูลส่วนบุคคล แต่เหมือนเว็บไซต์ทั่วไป GitHub อาจบันทึกหมายเลข IP ไว้ในระบบของเขา

Photos

If you tap save on a result card, the app asks for permission to add that image to your photo library. It does not read, upload, or scan your existing photos.

ถ้าคุณกดบันทึกการ์ดผลลัพธ์ แอปจะขอสิทธิ์เพิ่มรูปนั้นลงในคลังรูปภาพเท่านั้น แอปไม่ได้อ่าน อัปโหลด หรือสแกนรูปที่มีอยู่แล้ว
